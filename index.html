Computer Organization & Architecture Reference

Fundamental COA concepts, formulas, mapping rules, and design trade-offs

Syllabus Reference
🎯

Cache Hit vs. Cache Miss

A Cache Hit occurs when the processor requests a word and its tag matches an entry in the designated cache set/line with a valid bit of 1. Data is serviced in Hit Time. A Cache Miss triggers a main memory read stall where the entire block is fetched across the bus into cache with a Miss Penalty.

Hit Ratio = Hits / (Hits + Misses)
📌

Direct Mapping

Each memory block maps to exactly one cache line determined by Line = Block mod CacheLines.

  • Pros: Simplest hardware, single comparator, lowest hit latency.
  • Cons: Vulnerable to severe conflict thrashing when multiple active blocks map to the same line.
Line = Block % Lines | Tag = ⌊Block / Lines⌋
🔀

Set-Associative Mapping

The cache is partitioned into S = Lines / Ways sets. Each memory block maps to a set: Set = Block mod S, and can reside in any of the K ways within that set.

  • Pros: Significantly reduces conflict misses without the extreme comparator cost of fully associative caches.
  • Cons: Requires K parallel comparators and replacement logic.
Set = Block % (Lines / Ways)
🌐

Fully Associative Mapping

A memory block can be placed in any cache line. There is no index field; the entire block number acts as the Tag.

  • Pros: Zero conflict misses; optimal cache line utilization.
  • Cons: Requires N parallel comparators (where N = cache lines), making it expensive for large caches. Common in small TLBs.
Tag = Block | Search All Lines in Parallel
⏱️

Replacement Policies

When a candidate set is full upon a miss, a replacement algorithm determines the victim block:

  • FIFO (First-In, First-Out): Replaces the block that has resided in cache longest, regardless of recent access frequency.
  • LRU (Least Recently Used): Replaces the block whose most recent access timestamp is oldest. Exploits temporal locality.
  • LFU (Least Frequently Used): Replaces the line with minimum access counter.
📐

The 3 C's Miss Model & AMAT

Compulsory (Cold): First access to a block; unavoidable.
Capacity: Cache cannot contain all working set blocks.
Conflict (Collision): Multiple blocks compete for the same set in direct or set-associative caches.
AMAT (Average Memory Access Time):

AMAT = Hit Time + (Miss Rate × Miss Penalty)
